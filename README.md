# CivicLens

**Work in Progress**

This project is currently under active development. Some features and integrations, including the n8n workflow, are being improved and updated.

CivicLens is a web application designed to help citizens report civic issues.

## Features

- Upload an image of a civic issue
- Add a description of the problem
- Report issues through the application
- Verify image resolution
- Process submitted reports using API routes

## Technologies Used

- Next.js
- React
- JavaScript
- CSS

npm run dev
